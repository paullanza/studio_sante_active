# Mockups

The approved mockups for Total Restructure, exported from the design canvas. They are reference files, not app code: read the inline styles for sizes, spacing, order and wording. Fields and buttons use a few shared classes (`.tile`, `.code`, `.btn-gold`, `.btn-text`) in each file's `<style>` block, mirroring `docs/ui.md` « Forms » and « Buttons ». They load Google Fonts and a canvas script, so they may not render fully when opened locally; the app self-hosts its fonts instead.

| File | What it shows |
| -- | -- |
| `Main.html` | Design sheet: colours, type, buttons, badges, fields, progress bars, the top nav |
| `Service.html` | Service page (journey 2.4) |
| `Saisir.html` | « Saisir » page, séance and consultation tabs (3.1, 4.1) |
| `Client.html` | Client page (2.2) |
| `references.md` | Links to outside designs for inspiration (client lists and client management) |

Every person in them is made up. Keep it that way: never put real client or staff data here.
